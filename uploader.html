Leonardo USB uploader

For the Ibtikar Maker Hexagon (ATmega32U4 / Caterina). This uploader uses the AVR109 protocol directly and deliberately separates the 1200-baud reset from bootloader selection, so the bootloader's new USB port can be selected after it appears.

Important: This page uploads a compiled Intel HEX file. It does not compile your .ino sketch.

STEP 1

Choose compiled firmware

Choose the .hex file produced by compiling your sketch for Arduino Leonardo. Do not select an .ino file.

STEP 2

Reset into Caterina bootloader

Connect the Maker by USB, then click this. The page opens its normal USB serial port at 1200 baud and closes it to request the Leonardo bootloader reset.

STEP 3

Select the bootloader port and upload

Wait for the board to disappear and reappear, then click below. In the browser picker, select the newly appeared Leonardo/Caterina device (not the old normal-mode port).

Ready. Select a .hex file to begin.

Board settings

Arduino Leonardo · ATmega32U4 · AVR109 / Caterina · 57600 baud · 16 MHz · 5 V · 28672-byte application area.

This uses browser Web Serial, available in Chrome on ChromeOS. It has not yet been physically validated on your particular Maker Hexagon.
